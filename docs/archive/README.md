# Tài liệu lưu để đối chiếu

Các tài liệu/diagram IELTS và thiết kế database trước khi đổi đề tài chỉ là lịch sử tham khảo. Không áp dụng SQL ở đây cho English Learning.

Schema app mới chỉ lấy từ source/server/src/main/resources/db/migration; xem DATABASE_DESIGN.md ở thư mục gốc. Kết quả hiện tại nằm ở statics/results/module-1-validation.md. Kết quả bản cũ trong statics/results/archive không đại diện bản mới.
